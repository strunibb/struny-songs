# Струны будущего — разборы песен

Современная библиотека платных разборов песен на гитаре. Посетитель находит песню, смотрит состав материала и переходит в Telegram к Никите для покупки.

## Возможности

- мгновенный поиск по песням и исполнителям;
- уровни «Начинающий», «Любитель», «Хардкор» и «Фингерстайл»;
- фильтры по содержанию и сложности;
- отдельные страницы разборов с видео- и PDF-превью;
- готовое сообщение для покупки через Telegram;
- закрытая админка `/admin` для добавления, редактирования и публикации разборов;
- загрузка обложек и закрытых PDF-файлов;
- адаптивный интерфейс с мобильной панелью покупки.

## Запуск

```bash
npm ci
npm run dev
```

Для работы админки нужны переменные окружения из `.env.example`. Каталог хранится в Cloudflare D1, файлы — в R2. Логические имена подключений указаны в `.openai/hosting.json`.

## Основные страницы

- `/` — главная и новые разборы;
- `/songs` — полный каталог;
- `/songs/[slug]` — страница песни;
- `/admin` — закрытая панель управления.
